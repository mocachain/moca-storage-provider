# Project Agent Rules

## GitHub Review Comments

- Write all GitHub issue comments, pull request reviews, inline review comments, and replies in English.
- Before submitting a comment, scan it for Chinese characters. Do not submit it if any are present; translate it to English first.
- Validate comment text with `scripts/check-github-comment.sh` before sending it to GitHub.
- Keep technical identifiers, code, paths, and quoted logs unchanged when they are needed for precision.
